接管范围

网址是 http:// / https:// 时，只有这些 MIME 会被从“下载”改成内联渲染：

    其它类型一律不碰，包括 application/octet-stream（很多对象存储给所有文件都用它）和 application/vnd.ms-excel（可能是真正的 xls 二进制）。这些文件仍然会被下载，下载后可以从工具栏图标打开本地查看页查看。

    本地文件（file://）管不了 .csv

    本地文件不经过 HTTP，扩展没有响应头可改，类型完全由 Firefox 自己决定。实测（Firefox 159）：

    文件默认改 ~/.mime.types 后
    .csv下载还是下载（映射成 text/plain 甚至 image/png 都没用，与内容无关）
    .tsv下载内联显示，能渲染成表格
    .tab、未登记扩展名内联内联

    两头都堵：.csv 的扩展名映射改不动（和 .txt 一样属于不可覆盖的内置映射）， 而且 text/csv 本身就在 Firefox“不当纯文本渲染”的硬编码黑名单里 （nsContentUtils::IsPlainTextType 的 kNonPlainTextTypes，含 csv / x-csv / comma-separated-values / tab-separated-values / tsv）。这两处都没有 about:config 开关—— 上面截图区里的 helpers.*_mime_types_file、network.mimesniff.* 都改不了它。

    所以本地 .csv 请用工具栏图标打开查看页（拖拽 / 选择 / Ctrl+V）， 或者把目录用 python3 -m http.server 8000 起成 http 再访问 —— http 上的响应头改写照常生效。

    本地 .tsv 想要直接变表格：~/.mime.types 加 type=text/plain exts=tsv,tab （helpers.private_mime_types_file 默认就指向 ~/.mime.types）， 再打开上面的「访问文件 URL」开关。注意这里管用的原因是把类型改成了 text/plain， 而不是留在 text/tab-separated-values——后者也在黑名单里。
